# library-api


(HTTP API) для управления процессами учета, выдачи и возврата книг в библиотеке. Проект выполнен на языке Go с использованием СУБД SQLite.

## Основные возможности
* **Управление книгами**: добавление новых поступлений и просмотр всего каталога книг с их текущим статусом (`Available` / `Issued`).
* **Управление читателями**: регистрация пользователей в системе с автоматическим присвоением уникального UUID.
* **Библиотечные операции**: выдача книг читателям на 14 дней и фиксация возврата книг обратно в фонд.
* **Безопасность данных**: критические операции изменения данных (выдача книги) защищены SQL-транзакциями.
* **Структурированное логирование**: все действия сервера логируются напрямую в стандартный вывод (`stdout`) в формате JSON с временными метками.

## Структура проекта
Проект имеет плоскую модульную структуру:
* `main.go` — точка входа, настройка роутинга и запуск HTTP-сервера.
* `handlers.go` — обработчики HTTP-запросов (валидация JSON, вызов бизнес-логики, логирование).
* `db.go` — логика взаимодействия с базой данных SQLite (SQL-запросы, транзакции).
* `models.go` — описание структур данных (книги, пользователи, записи выдачи).
* `library.db` — локальный файл базы данных SQLite (создается автоматически).

## Архитектура базы данных
База данных состоит из трех связанных таблиц:
1. `Books` — информация о книгах. Уникальный идентификатор — текстовый UUID.
2. `Users` — данные зарегистрированных читателей.
3. `Issues` — связующая таблица «выдачи». Реализует связь «многие со многими» между книгами и читателями (один ко многим от каждой таблицы к `Issues`).

## Запуск проекта

go mod tidy

Bash

go run .

После запуска сервер начнет слушать входящие запросы по адресу: http://localhost:8080.
Примеры cURL-запросов

1. Добавление новой книги
Bash

curl -X POST http://localhost:8080/books \
  -H "Content-Type: application/json" \
  -d '{"title": "Преступление и наказание", "author": "Фёдор Достоевский", "isbn": "978-5-389-04922-2", "year": 1866}'

2. Получение списка всех книг
Bash

curl -X GET http://localhost:8080/books

3. Регистрация нового читателя
Bash

curl -X POST http://localhost:8080/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Алексей Иванов", "email": "ivanov@mail.ru"}'

4. Выдача книги читателю
Bash

curl -X POST http://localhost:8080/issues \
  -H "Content-Type: application/json" \
  -d '{"user_id": "СЮДА_UUID_ПОЛЬЗОВАТЕЛЯ", "book_id": "СЮДА_UUID_КНИГИ"}'

5. Возврат книги в библиотеку
Bash

curl -X POST http://localhost:8080/returns \
  -H "Content-Type: application/json" \
  -d '{"book_id": "СЮДА_UUID_КНИГИ"}'
